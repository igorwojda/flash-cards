# 📝 Definition

Term and its definition, studied in both directions.

## Structure

Card Type: Basic (and reversed card)

Side 1: Term
Side 2: Definition

## Tip

Definition must point to only one term, because card is also studied in reverse.
If term has multiple names, list them and add hint e.g. `(3 names)`.

## Example

Side 1:  

```
Model Routing
```

Side 2:  

```
Process of automatically selecting the most appropriate language model for a given request
```
