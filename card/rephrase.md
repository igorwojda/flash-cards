# 📝 Rephrase

Clumsy or wordy phrase on one side, better phrasing on the other.
Use to build vocabulary and more natural expressions.

## Structure

Card Type: Basic

Side 1: `Rephrase:` and the original phrase
Side 2: Better phrase

## Tip

Use AI to find better phrasing - `Rephrase 5x...`

## Example

Side 1:  

```
Rephrase:
Does not have side-effects
```

Side 2:  

```
Is side-effect free
```
