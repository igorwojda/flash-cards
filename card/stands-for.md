# 📝 Acronym Stands For

Acronym and its expansion.

## Structure

Card Type: Basic

Side 1: `<Acronym> stands for:`
Side 2: Expansion

## Tip

Keep `stands for:` in Side 1, so it is clear expansion is expected (not definition).

## Example

Side 1:  

```
CSS stands for:
```

Side 2:  

```
Cascading Style Sheets
```
