# 📝 Versus

Two or three related terms, definition of each to tell them apart.

## Structure

Card Type: Basic

Side 1: Two or three **related** terms
Side 2: Definition of each term

## Tip

Focus on the key difference. If definitions share structure, use [Versus With Pattern](versus-with-pattern.md).

## Example

Side 1:  

```
Concurrent vs Parallel
```

Side 2:  

```
Concurrent - multiple tasks execute during overlapping time periods
Parallel - multiple tasks execute at the same time on multiple cores
```
