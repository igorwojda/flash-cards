# 📝 Question And Answer

Simple question and answer.

Common question forms:

- Why X? - reason behind a fact or choice (e.g. Why is XML preferred over JSON for LLM input?)
- Why is example X correct/incorrect? - judge a given example
- How to do X? - procedure or command, numbered steps if order matters
- What are pros/cons of X? - trade-offs of a solution or approach

## Structure

Card Type: Basic

Side 1: Question
Side 2: Answer

## Tip

Add hint to rule out near-miss answers, e.g. `(3 names)`, `(general)`.

## Example

Side 1:  

```
What does Maestro test?
```

Side 2:  

```
User journeys and variations of these journeys
```
