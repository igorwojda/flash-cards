# 📝 Enumerate N Items

Complete list of N items (pillars, steps, types, principles).
Number in Side 1 tells how many items to recall.

## Structure

Card Type: Basic

Side 1: `<N> <items> of X`
Side 2: Complete list of N items

## Tip

Use `Item - short explanation` format for each line.
For a sample (not a complete list), use [Provide Examples](provide-examples.md).

## Example

Side 1:  

```
3 pillars of good Context Engineering
```

Side 2:  

```
Correctness - include only correct information
Completeness - include all relevant information
Conciseness - minimize input size
```
