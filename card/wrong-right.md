# 📝 Wrong → Right

Wrong statement, habit or approach on one side, corrected version on the other.
Use ❌ and ✅ to mark each side.

## Structure

Card Type: Basic

Side 1: ❌ Wrong version
Side 2: ✅ Right version

## Tip

Use for mindset, habit or approach. For wording only, use [Rephrase](rephrase.md).

## Example

Side 1:  

```
❌ Focus on today’s results
```

Side 2:  

```
✅ Focus on your trajectory
```
