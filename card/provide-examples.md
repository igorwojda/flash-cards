# 📝 Provide Examples

Question asks for a specific number of examples (e.g. "3 Examples of ..."). 
Keep it small (3-5): a sample, not a full list.

## Structure

Card Type: Basic

Side 1: Question asking for examples
Side 2: List of examples

## Tip

To recall a complete list, use [Enumerate N Items](enumerate-n-items.md).

## Example

Side 1:  

```
3 Examples of using Fabric
```

Side 2:  

```
1. Sumarize youtube video
2. Analize claims in a debate
3. Create meeting summary
```
