## 📝 Question And Answer (Basic Card Type)

Side 1 contains question, Side 2 contains answer.

### Example

Side 1:  

```kotlin
What Maestro tests?
```

Side 2:  

```kotlin
Test user journeys and variations of these journeys 
```

## 📝 Question And Answer Example (Basic Card Type)

Side 1 contains question, Side 2 contains answer contains example.

### Tips

It’s good to mention numer of examples answer card contains.

### Example

Side 1:  

```kotlin
3 Examples of using Fabric
```

Side 2:  

```kotlin
1. Sumarize youtube video
2. Analize claims in a debate
3. Create meeting summary
```

## 📝 Versus

Side 1: Two or three **related** terms

Side 2: Contains definitions of these terms.

Optionally provide pattern if each definition has structure e.g.

Side 1: 2–3 related terms. Side 2: definition of each.
Optional: add a tip on Side 1 when all definitions share a structure.

### Example

### Example (With Pattern)

Side 1:  

```kotlin
Verify vs Evaluate
Pattern: Definition -> Result
```

Side 2:  

```kotlin
Verify - check against a fixed criterion or truth → binary result (pass/fail)
Evaluate - judge against a scale of quality or value → graded result (score/rating)
```

## 📝 Stands For (Basic Card Type)

Side 1 contains acronym, Side 2 contains expansion.

### Example

Side 1:  

```kotlin
CSS stands for:
```

Side 2:  

```kotlin
Cascading Style Sheets
```

## 📝 Definition (Basic And Reverse Card Type)

Side 1 contains term, Side 2 contains definition.

### Example

Side 1:  

```kotlin
Model Routing
```

Side 2:  

```kotlin
Process of automatically selecting the most appropriate language model for a given request
```
