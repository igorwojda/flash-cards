# Flash Card Types

Common flashcard types, typically used with [Anki](https://apps.ankiweb.net/).

- [Question And Answer](card/question-and-answer.md)
- [Question And Answer Example](card/question-and-answer-example.md)
- [Versus](card/versus.md)
- [Stands For](card/stands-for.md)
- [Definition](card/definition.md)

# General Rules

1. Avoid Punctuation and the end of sentences or bullet points
2. Keep text minimal and compact
    1. Use AI to compact text - `Compact this and rephrase 3x...`
    2. Use AI to generate few versions to pick one suits you best - `Rephrase 3x...`
3. Add deck name to all card types to provide context
