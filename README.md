# Flash Card Types

Common flashcard types, typically used with [Anki](https://apps.ankiweb.net/).

- [Question And Answer](card/question-and-answer.md) - question on one side, answer on the other
- [Provide Examples](card/provide-examples.md) - question asking for a given number of examples, list of examples as answer
- [Versus](card/versus.md) - two or three related terms, definition of each to tell them apart
- [Versus With Pattern](card/versus-with-pattern.md) - like Versus, with a shared `(pattern)` structure for multi-aspect definitions
- [Acronym Stands For](card/stands-for.md) - acronym and its expansion
- [Definition](card/definition.md) - term and its definition, studied in both directions
- [Cloze](card/cloze.md) - sentence with a single key part hidden
- [Multi Cloze](card/multi-cloze.md) - sentence with multiple related parts hidden, one card per gap number
- [Wrong → Right](card/wrong-right.md) - wrong statement or approach and its corrected version
- [Rephrase](card/rephrase.md) - clumsy phrase and better phrasing

# General Rules

1. Keep cards compact and atomic
2. refine cards over time
3. Avoid Punctuation and the end of sentences or bullet points
4. Keep text minimal and compact
    1. Use AI to compact text - `Compact this and rephrase 3x...`
    2. Use AI to generate few versions to pick one suits you best - `Rephrase 3x...`
5. Add deck name to all card types to provide context
6. Add diagrams, screenshots, and other visual elements to cards
